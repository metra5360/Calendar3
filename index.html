Дві комірки на день — ваша та іншого користувача. Натисніть на колір, щоб позначити

Як підключити Supabase (синхронізація між двома користувачами)
  1. Створіть проєкт на supabase.com (або відкрийте вже існуючий).
  2. У SQL Editor виконайте SQL з блоку нижче — він створить таблицю marks, політики доступу та увімкне Realtime.
  3. У Project Settings → API скопіюйте Project URL і anon public ключ.
  4. Вставте їх у два значення вгорі цього файлу: SUPABASE_URL і SUPABASE_ANON_KEY (знайдіть блок «НАЛАШТУВАННЯ SUPABASE», Ctrl+F).
  5. Відкрийте файл у браузері. Другий користувач відкриває цей самий файл (або копію), вводить своє ім'я — і обидва бачите позначки одне одного миттєво.
-- Таблиця позначок: один рядок = колір одного дня для одного користувача
-- Якщо створювали таблицю за старою версією (з періодами) — спочатку видаліть її:
drop table if exists public.marks;

create table if not exists public.marks (
  date       date not null,                              -- день, напр. 2026-10-20
  user_name  text not null check (char_length(user_name) between 1 and 40),
  color      text not null check (color in ('green','yellow','red')),
  updated_at timestamptz not null default now(),
  primary key (date, user_name)
);

-- Доступ: анонімний ключ, політики відкриті (достатньо для двох довірених людей)
alter table public.marks enable row level security;

create policy "public read"   on public.marks for select to anon using (true);
create policy "public insert" on public.marks for insert to anon with check (true);
create policy "public update" on public.marks for update to anon using (true) with check (true);
create policy "public delete" on public.marks for delete to anon using (true);

-- Realtime: миттєві оновлення в обох браузерах
alter publication supabase_realtime add table public.marks;
alter table public.marks replica identity full;

Ключ anon і політики «все дозволено» — це нормально лише для приватного календаря на кілька людей: кожен, хто має ключ і цей файл, може читати та змінювати позначки. Не зберігайте в такій таблиці конфіденційні дані.
